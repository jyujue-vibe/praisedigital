The problem

Did the client change something, or did you?

Every motion designer knows the moment: you open v2 of a project and something feels off — but what exactly changed?

Scrubbing through timelines layer by layer wastes time and still misses things: a slipped out point, a nudged position value, a quietly edited line of text. RoundDiff replaces the guesswork with a complete, frame-accurate list of every change between two versions.

What it catches

Every category of change, in one list

RoundDiff walks both comps layer by layer and property by property, then reports the differences grouped by category — nothing eyeballed, nothing skipped.

Comp settings

Frame rate, duration, and dimensions — the project-level changes that are easiest to overlook and hardest to spot by eye.

Layers

Layers added, removed, or renamed between versions — matched up and listed, so a swapped asset never slips through.

Timing

In and out points compared with frame-accurate deltas — a slip shows up as exactly what it is, e.g. +25f.

Transforms

Position, scale, rotation, and opacity — static values and keyframes alike, reported old value → new value.

Effects

Effects added or removed, parameter changes, enabled and disabled states, and effect keyframes.

Text

Source text edits on text layers — see what the copy said in the old version and what it says now.

Workflow

Built for revision rounds, not just one comparison

A diff list is only useful if it plugs into how you already work. RoundDiff's results are navigable, saveable, and shareable.

Double-click to jump

Double-click any result and RoundDiff opens the comp, selects the layer, and moves the playhead to the exact frame where the change lives.

Snapshots

Save a JSON snapshot of any comp, then compare your current work against it days later — no need to keep duplicate comps cluttering the project.

CSV export

Export the full result list to CSV and hand a client or teammate a precise, line-by-line change log for the round.

Category filters

Filter results by category — timing only, effects only, whatever the round is about — to focus on what matters and hide the noise.

FAQ

Questions, answered

Which After Effects versions are supported?

RoundDiff is an ExtendScript ScriptUI panel — it runs inside After Effects itself and needs no third-party plug-ins. It has been tested on After Effects 2023 on Windows.

How do snapshots work?

From the panel, save any comp's current state as a JSON snapshot file. Later — even days later, in a different session — load that snapshot and compare any comp against it, exactly as if the old version were still open.

How do I install it?

Copy the RoundDiff file into After Effects' ScriptUI Panels folder, restart After Effects, and open RoundDiff from the Window menu. It docks alongside your other panels.
